# MQV in openQSE: SC26 demo

Material for MQV's part of the openQSE demo at SC26: a user runs quantum programs on MQV's resources MAQCS, EQE1 and AWS through openQSE.

| Path | Content |
|---|---|
| `demo.md` | The demo: steps, what to say, and the preparation |
| `slides/mqv-doe-dry-run.pptx` | Slides for the 3-minute slot of the DOE booth dry run |
| `slides/source/` | Source of the slides |
| `diagrams/` | The openQSE stack diagram (draw.io and PNG) and the QPU drawing |

Running the demo needs access to the openQSE testbed VM and an MQP-API token.
